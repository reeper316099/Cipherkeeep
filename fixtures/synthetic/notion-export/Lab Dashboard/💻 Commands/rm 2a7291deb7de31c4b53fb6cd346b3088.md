# rm

Category: File System
Example: rm old.txt
Explanation: delete files
Syntax: rm \[target\]

## 📌 What it does

Removes files or folders permanently.

---

## ⚙️ Basic Syntax

rm \[target\]

---

## 🧩 Arguments

(Inputs the command takes.)

- target → what to remove

---

## 🔧 Common Options (Flags)

| Option | Meaning |
| --- | --- |
| -r | recurse into folders |
| -f | never prompt |
| -i | prompt each time |

---

## 💡 Examples

```bash
rm old.txt = "delete old.txt"
```

| Command | Results |
| --- | --- |
| `rm one` | Runs *rm* on **one**. |
| `rm -i one` | Same, but with a prompt. |
