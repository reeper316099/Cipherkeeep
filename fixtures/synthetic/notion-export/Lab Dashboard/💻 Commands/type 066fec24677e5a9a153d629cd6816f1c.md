# type

Category: General
Example: type ls
Explanation: how a name resolves
Syntax: type \[command\]

## 📌 What it does

Tells you if a name is a builtin, alias or file.

---

## ⚙️ Basic Syntax

type \[command\]

---

## 🧩 Arguments

- command → name to look up

---

## 💡 Examples

```bash
type ls = "resolve ls"
```
