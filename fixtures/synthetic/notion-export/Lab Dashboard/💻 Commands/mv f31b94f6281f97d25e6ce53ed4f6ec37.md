# mv

Category: File System
Example: mv a.txt dir
Explanation: move or rename
Syntax: mv \[source\] \[destination\]

## 📌 What it does

Moves or renames files.

---

## ⚙️ Basic Syntax

mv \[source\] \[destination\]

---

## 🧩 Arguments

- source → item to move
- destination → new place or name

---

## 🔧 Common Options (Flags)

| Option | Meaning |
| --- | --- |
| -i | confirm overwrite |
| -n | never overwrite |

---

## 💡 Examples

```bash
mv a.txt dir = "move a.txt into dir"
```

| Command | Results |
| --- | --- |
| `mv one` | Runs *mv* on **one**. |
| `mv -i one` | Same, but with a prompt. |
