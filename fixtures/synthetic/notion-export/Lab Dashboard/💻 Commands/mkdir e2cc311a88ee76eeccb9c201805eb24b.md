# mkdir

Category: File System
Example: mkdir demo
Explanation: create folders
Syntax: mkdir \[directory\]

## 📌 What it does

Makes new directories.

---

## ⚙️ Basic Syntax

mkdir \[directory\]

---

## 🧩 Arguments

- directory → name to create

---

## 💡 Examples

```bash
mkdir demo = "create demo"
mkdir a b = "create two folders"
```
