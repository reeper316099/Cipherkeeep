# cd

Category: File System
Example: cd ~
Explanation: change directory
Syntax: cd \[directory\]

## 📌 What it does

Moves into another folder.

---

## ⚙️ Basic Syntax

cd \[directory\]

---

## 🧩 Arguments

- directory → destination

---

## 🔧 Common Options (Flags)

| Option | Meaning |
| --- | --- |
| cd | jump home |
| cd - | jump back |
| cd .. | one level up |

---

## 💡 Examples

```bash
cd ~/projects = "enter projects"
```
