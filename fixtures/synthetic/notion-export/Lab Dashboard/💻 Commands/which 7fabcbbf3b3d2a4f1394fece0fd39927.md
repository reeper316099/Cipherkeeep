# which

Category: General
Example: which ls
Explanation: locate an executable
Syntax: which \[command\]

## 📌 What it does

Prints the path of a program.

---

## ⚙️ Basic Syntax

which \[command\]

---

## 🧩 Arguments

- command → program name

---

## 💡 Examples

```bash
which ls = "path of ls"
```
