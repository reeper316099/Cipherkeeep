# less

Category: File System
Example: less log.txt
Explanation: page through a file
Syntax: less \[filename\]

## 📌 What it does

Scrollable file viewer.

---

## ⚙️ Basic Syntax

less \[filename\]

---

## 🧩 Arguments

- filename → file to view

---

## 🔧 Commands

| Option | Meaning |
| --- | --- |
| space | next page |
| b | previous page |
| /text | search forward |
| q | quit |

---

## 💡 Examples

```bash
less log.txt = "view log.txt"
```
