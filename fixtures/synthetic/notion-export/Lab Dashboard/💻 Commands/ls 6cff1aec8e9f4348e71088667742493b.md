# ls

Category: File System
Example: ls -al
Explanation: list directory entries
Syntax: ls \[flags\] \[directory\]

## 📌 What it does

Prints the entries of a directory.

---

## ⚙️ Basic Syntax

ls \[flags\] \[directory\]

---

## 🧩 Arguments

- directory → folder to list

---

## 🔧 Common Options (Flags)

| Option | Meaning |
| --- | --- |
| -a | include dotfiles |
| -l | long listing |
| -h | sizes in K/M/G |
| -t | newest first |

---

## 💡 Examples

```bash
ls /var = "list /var"
ls --color=auto = "colourised output"
ls -lh ~ = "long listing of home, human sizes"
```
