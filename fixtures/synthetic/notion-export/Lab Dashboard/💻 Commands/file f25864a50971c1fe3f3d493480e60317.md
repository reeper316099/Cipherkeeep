# file

Category: File System
Example: file photo.jpg
Explanation: detect file type
Syntax: file \[filename\]

## 📌 What it does

Guesses a file type from content.

---

## ⚙️ Basic Syntax

file \[filename\]

---

## 🧩 Arguments

- filename → target file

---

## 💡 Examples

```bash
file photo.jpg = "report the type of photo.jpg"
```
